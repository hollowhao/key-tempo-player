# キー変更・テンポ変更プレイヤー

曲のキー（音程）とBPMを**別々に**変えられる、ブラウザで動く無料の音楽プレイヤーです。
インストール不要。音楽ファイルはアップロードされず、すべてお使いのブラウザの中で処理されます。

**▶ 使ってみる：https://hollowhao.github.io/key-tempo-player/**

## できること

- キーを半音ずつ変更（±12半音）。テンポは変わりません
- BPMを1ずつ変更（Shiftで5ずつ）。キーは変わりません
- 曲のBPMを自動で検出（÷2・×2・TAP・直接入力で修正も可能）
- プレイリスト、リピート、ドラッグ＆ドロップでの曲追加
- PC版の Chrome / Edge では、別タブで再生中の動画・音楽サイトの音声を取り込んでキーを変えて聴けます

## 操作方法

| キー | 動作 |
| --- | --- |
| ↑ ↓ / W S | キーを半音ずつ上げ下げ |
| ← → / A D | BPMを1ずつ上げ下げ |
| Shift ＋ ← → / A D | BPMを5ずつ上げ下げ |
| Space | 再生 / 一時停止 |
| N / P | 次の曲 / 前の曲 |
| R | キーとBPMを元に戻す |

スマホでは画面のボタンで同じ操作ができます。

## 対応形式

MP3、AAC / M4A、WAV、FLAC、OGG、Opus、WebM、MP4（音声のみ）など、ブラウザが再生できる形式に対応しています。
WMA は多くのブラウザで非対応、AIFF と ALAC は主に Safari で再生できます。

## タブ音声の取り込み（PCのみ）

1. 別のタブで動画・音楽サイトを開いて再生する
2. プレイヤーの「タブ音声を取り込む」を押し、そのタブを選ぶ
3. 「タブの音声も共有する」をオンにして「共有」を押す
4. ↑↓（W S）でキーを変える

取り込み中はテンポを変えられないので、各サイトの再生速度の設定を使ってください。

## ご利用にあたって

- 音声は外部に保存・送信されることはありません
- タブ音声の取り込みは、各サイトの利用規約の範囲で個人の視聴にお使いください
